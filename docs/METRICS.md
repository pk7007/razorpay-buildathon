# Metrics — AI Finance Controller

> Honest reporting only. Numbers here are regenerated by
> `scripts/run_reconciliation.py` against a labelled fixture set. Do not edit by hand.

## Definitions

| Metric | Definition |
| --- | --- |
| **Auto-match rate** | entries matched without human review / total entries |
| **Precision** | correct matches / total matches proposed |
| **Recall** | correct matches / total true matches in the labelled set |
| **Exception accuracy** | exceptions with the correct category / total exceptions |
| **Deterministic share** | matches from Stage 1 / total matches |
| **Agent share** | matches from Stage 2 (LLM) / total matches |
| **Replay stability** | 1.0 if a full re-run reproduces the same groups |

## Method notes

- The labelled set lives in `data/sample/labels.json`: `{group_id: [entry_id, ...]}`.
- Precision/recall are computed on *pairs* (two entries in the same true group),
  which avoids rewarding trivially-large groups.
- Every headline number in the pitch video must be traceable to a committed
  `out/metrics.json` and the exact input files used.
